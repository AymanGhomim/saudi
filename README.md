# Hematology & Hemostasis Conference 2026

Official conference website for the Second International Hematology and
Hemostasis Conference, held 3–5 May 2026 at Le Méridien Al Khobar.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Checks

```bash
npm run build
npm test
npm run lint
```

The website source is under `app/`, and static media is under `public/media/`.
